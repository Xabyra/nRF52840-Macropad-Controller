# Macropad nRF52840 Configuration Software (Flutter)

This directory contains the cross-platform desktop application for configuring the Macropad nRF52840. Developed with Flutter, this application provides a user-friendly graphical interface to customize all aspects of the macropad's functionality via Bluetooth Low Energy (BLE).

## Key Technologies

*   **Flutter (Dart)**: The UI framework for building natively compiled applications for mobile, web, and desktop from a single codebase.
*   **Bluetooth Low Energy (BLE) Communication**: The application communicates with the Macropad firmware using a custom BLE GATT service to read and write configuration data. (A BLE plugin like `flutter_blue_plus` or similar would typically be used here for Flutter BLE capabilities).
*   **Desktop Platforms**: Supports Windows and Linux desktop environments.

## Features

*   **BLE Connection Management**: Discover, connect to, and manage the Macropad device.
*   **Real-time Configuration Readout**: Displays the current active profile, key assignments, backlight status, and battery level from the connected macropad.
*   **Profile Management**: Create, edit, and switch between multiple macropad profiles.
*   **Keymap Editor**: Visually assign actions to each key in the 3x4 matrix and the rotary encoder (button, clockwise, counter-clockwise turns).
    *   Supported Action Types: Standard keyboard keys (with modifiers), mouse clicks/scrolls, backlight control, and custom sequences.
*   **Sequence/Macro Editor**: Define and store complex sequences of key presses with individual delays.
*   **Backlight Control**: Adjust backlight brightness and toggle its on/off state.
*   **Persistent Storage**: Writes updated configurations back to the macropad's non-volatile memory.
*   **Export/Import**: Functionality to export the entire device configuration (profiles and sequences) as a JSON string for backup or sharing.

## Compilation and Running

### Prerequisites

1.  **Flutter SDK**: Ensure you have the Flutter SDK installed and configured.
    *   Follow the official Flutter installation guide: flutter.dev/docs/get-started/install
2.  **Desktop Development Setup**: Enable desktop support for your target platforms.
    ```bash
    flutter config --enable-windows-desktop
    flutter config --enable-linux-desktop
    # You might also need to install platform-specific dependencies, e.g., for Linux:
    # sudo apt install clang cmake ninja-build pkg-config libgtk-3-dev
    ```
3.  **IDE (Optional but Recommended)**: Visual Studio Code with the Flutter extension, or Android Studio with the Flutter plugin.

### Building the Application

1.  Navigate to the `Software` directory of this project:
    ```bash
    cd c:\Users\Vitalii\Desktop\Macropad nrf52840\Software
    ```
2.  Get Flutter dependencies:
    ```bash
    flutter pub get
    ```
3.  Build for your target desktop platform:
    *   **Windows**:
        ```bash
        flutter build windows
        ```
        The executable will be found in `build\windows\runner\Release\` (or `Debug\`).
    *   **Linux**:
        ```bash
        flutter build linux
        ```
        The executable will be found in `build/linux/x64/release/bundle/` (or `debug/`).

### Running the Application

1.  Ensure you are in the `Software` directory.
2.  Run the application directly from your IDE or using the Flutter CLI:
    *   **Windows**:
        ```bash
        flutter run -d windows
        ```
    *   **Linux**:
        ```bash
        flutter run -d linux
        ```
    This will launch the application in debug mode, allowing for hot reload. For a release build, run the executable generated by `flutter build`.

## Usage

1.  Launch the Macropad Configuration application.
2.  Ensure your Macropad nRF52840 device is powered on and advertising (or connected).
3.  Use the application's interface to scan for and connect to your macropad via BLE.
4.  Once connected, you can view and modify profiles, key assignments, sequences, and backlight settings.
5.  Changes made in the application will be sent to the macropad and saved to its internal flash memory.
